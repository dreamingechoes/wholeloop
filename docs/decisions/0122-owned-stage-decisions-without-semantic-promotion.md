# 0122 — Owned stage decisions without semantic promotion

- **Status:** Accepted
- **Date:** 2026-10-26

## Context

The runner already requires private named decisions for unattended routes, and the native planner/challenger host already produces independent bounded judgments. Their connection must preserve the exact original stage, requests and runtime ownership. A current machine judgment still cannot replace behavioral verification, legacy human approval or endpoint evidence.

## Decision

Add a fixed internal stage-decision component over the existing delegated-decision store. Derive required decision IDs/outcomes from the exact original route and grant. Require one exact current-plan request for every requirement, with no missing, extra, duplicate or cross-grant/revision request. Bound and credential-check metadata before retaining its immutable private root intent, then use the existing one-shot decision keys and original purpose budgets. Consume a private original-invocation marker before writing its descriptor. The marker fences invocation only; losing the descriptor, including before native registration, cannot buy another key or supply approval.

Share actual native stage registration, finite deadline narrowing and private process scopes between production and decision workers. Planner, challenger and boundary controls use the same registered runner. Relay caller cancellation and enforce the original root deadline even when a judgment ignores its signal. Missing replies remain unknown; repeating the component neither buys another judgment nor changes the original requests. A stage with no required decision needs no model or invented judgment.

Recover only an original private decision key's exact immutable record. A published head can repair a missing final locator only when its request digest agrees; a newer unrelated judgment cannot complete the old stage. Recheck original grant/plan, current named outcomes and positive native closure. Paused inspection performs no new decision or resume. Cancellation addresses original nonce channels only.

Return decision evidence as a component result rather than a whole-stage, QA or endpoint observation. Fixture-only, rejected, stale and incomplete decisions remain blocked or unknown. Preserve the existing decision head scope of run/plan/decision: callers may reuse an exact still-current global request across stages, but a new judgment fences its predecessor. Do not silently redefine an approval as per-unit or fabricate legacy owner agreement. Complete-route fixed factory, production of definition/build/acceptance artifacts, semantic hosts and public execution/endpoint wiring remain P6-10 technical work.

## Alternatives rejected

A generic passed-stage envelope would blur judgment and actual behavior. Launching headless gate clients directly would bypass original native purpose limits and runtime proof. Recreating keys after a lost response would grant duplicate decisions. Picking the newest record would allow another request to replace the original judgment. Changing old closed schemas or decision scope in place would reinterpret existing approvals. Treating an empty decision list as permission to ask a model or invent human agreement would add an unnecessary prerequisite.

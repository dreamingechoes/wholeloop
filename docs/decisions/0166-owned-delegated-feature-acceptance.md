# 0166 — Owned delegated feature acceptance

- **Status:** Accepted
- **Date:** 2026-10-29

## Context

Current whole-product readiness is necessary for acceptance, but it is not the independently authorized acceptance decision. The unattended route needs to join both without converting a machine judgment into human approval, selecting a new product after judgment, or replaying a decision when its original input is lost.

## Decision

Add a fixed acceptance-stage adapter over the same store's feature reader. Automatic execution requires intervention none, an active original grant and its explicit acceptance delegation. Other policies or missing delegation cannot inherit automatic approval. Capture the original context, deadline, signal and ownership predicate before asynchronous inspection; recheck authority and current product inputs before selecting judgment.

Consume one original input binding before capturing its budgeted artifact. The bounded input contains the exact product readiness, current criteria and original complete-product report. Keep its original stage/deadline and byte digest, validate it against the observed artifact ledger and original report, and require it in every delegated request. Losing the binding, consumption or artifact cannot buy another capture or decision. Retrying known not-yet-issued judgment still requires the same original binding and deadline; unresolved native prefixes remain protected by existing decision claims.

Use the existing independent planner/challenger mechanism through the registered native process function and a fixed same-store native decision host. Require actual closed zero-exit owners and canonical original outcome times inside the acceptance window. Reopen current product readiness before and after decision inspection, compare all semantic product identities rather than only a copied evidence field, require the unchanged original input/native vector and recheck active authority. A delegated rejection leaves the feature blocked despite passing product QA. Zero client exit alone cannot establish acceptance.

Inspection reads original evidence after pause or retirement without a selector or model replay. Revocation withdraws current eligibility; original nonce-bound cancellation remains available after revocation or loss of the input locator. The adapter records no human approval and performs no publication. Existing supervised/manual acceptance remains a separate controller path, rather than an inferred approval in this automatic adapter.

## Alternatives rejected

Passing directly from product readiness skips the named independent decision. Delegating before a complete current product exists lets judgment replace missing QA. Capturing a replacement input after interruption changes the basis of the original judgment. Accepting a stopped but late reviewer renews the parent budget. Treating rejection as uncertain native ownership conflates a known blocked result with an unclosed process. Silently truncating evidence would let the judgment inspect a different product; inputs above the existing bounded decision-evidence budget are refused intact.

# 0125 — Owned artifact production before delegated decisions

- **Status:** Accepted
- **Date:** 2026-10-26

## Context

The runner can execute owned unit workers and independent delegated judgments, but a judgment does not create the definition it evaluates. Reusing decision authority for all report production would make supervised planning require permission to approve its own output. Inventing work units for controller artifacts would change the approved dependency graph. Definition and acceptance data must remain proposals until the appropriate decisions and actual behavior checks establish more.

## Decision

Extract the existing original-budget read-only native transport into a shared core. Keep the delegated decision profile's exact v1 lease, paths, authorization, timing and event text. Add a separate internal artifact profile using source.read/report.write authority, the planner's unchanged no-workspace tool policy, an exact root-stage binding and shared evaluator capacity. Produce no synthetic execution unit or delegated decision. A changed deadline cannot buy a new purpose cell. Live root fencing applies before launch, completion and result settlement; historical artifact observation can read positively completed original work while paused.

Add an artifact-stage component for definition/plan proposals, builder plans and pre-builder acceptance definitions. Select the response schema and task in trusted controller code. Bind current source, plan, selected stage/unit target, original private native directory and journal-selected receipt; require exactly one bounded captured report, unchanged original inputs and positively closed native owners. Parse the exact captured bytes, capture pre-build snapshots before context selection and recheck them before input and reject outer execution/approval claims. Preparing a proposal records neither a legacy human agreement nor a delegated approval.

Validate scope and immutable revision relationships before retaining a delivery-plan proposal. Keep it in its exact captured artifact without reserving the next immutable plan revision: a rejected proposal must remain correctable before the accepted one is prepared/adopted. The internal descriptor distinguishes proposal data from pinned acceptance definitions. Preserve the original endpoint policy and enforce the granted envelope or exact plan-bound limits. Pin complete acceptance definitions through the existing owner/criterion validation before any builder admission. Builder plans retain their existing schema and need their independent approval. Actual suite behavior, source judgments and acceptance remain separate.

A consumed invocation and private locator precede native input. Missing/corrupt original bindings remain unknown; another request cannot silently replace them. Recover only the original journal-selected report and idempotent metadata writes, including while paused, without another model or allowance. Cancellation uses original private process nonces, including after revocation. Fixture output retains fixture provenance.

This is an internal component, not a new public result-import or execution command. Research-report production, full-stage decision composition, behavioral QA/repair/integration/acceptance and complete public route wiring remain technical P6-10 work.

## Alternatives rejected

A delegated decision is not a report-production permission. An extra implementation unit changes approved work and capacity. A model writing into controller state could fabricate approval or test evidence. Selecting the newest receipt misses the original journal binding. Preparing cases after builders lets observed failures rewrite the test definition. Reserving immutable plan history before a proposal passes its decisions prevents rejection/revision; adopting it also silently expands authority. Increasing ordinary test deadlines hides the original invocation limits.

## Verification

Retain the original native-purpose/decision and frozen-contract regressions. Exercise actual synthetic artifact workers without delegated decision permission, exact paused recovery, deadline/key reuse, missing leases, changed guidance/source/candidates and consumed locator loss. Check acceptance ownership and pre-builder pinning, bounded definition revisions and policy refusal, builder-plan separation, malformed/wrong-basis/uncertain reports, altered captured bytes and lost acceptance metadata recovery. Synthetic native observations do not certify authenticated accounts, live model policy, behavioral QA or a complete delivery route.

Fourteen model-free runner controls pass on macOS Node 24 and Linux Node 20.0.0. The journal retains exact hashes, elapsed times, corrected fixture/type failures and remaining native/account/full-route limits.

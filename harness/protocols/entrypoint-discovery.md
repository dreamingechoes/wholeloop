# Entrypoint discovery

- ⛔ `harness-entrypoints-not-guidance` — packaged native skills/roles carry a
  versioned routing marker. Inventory them, but exclude them from heuristic slot
  matching. Explicit slot tags/configured bindings remain valid; real repository
  guide conflicts still require a question. A routing marker proves no ownership,
  executable provenance or native permission isolation.

Keep markers valid in the native Markdown/TOML syntax and preserve role budgets.
Upgrade unchanged owned older output to receive the marker; preserve backups and
never rewrite an owner's previously configured binding automatically.

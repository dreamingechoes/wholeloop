# Evidence-backed learning decisions

- ⛔ `learning-human-call` — Pin the actual promise/evidence and current leaning. Require a counterargument against that exact plan, then a named person's written reason and exact acknowledgment of all unknowns/pending checkpoints. Re-plan after changed observations; never select an outcome from silence or profile.
- ⛔ `learning-iteration-link` — Iterate requires a real open framing draft linked to the decision evidence, with complete framing sections and unresolved questions labelled with answerers. Do not claim that the revised hypothesis was validated.
- ⛔ `learning-proposals-only` — Flag disablement/removal and code cleanup remain explicit proposals. This workflow has no flag, code mutation or publication host.

Self-reported evidence stays labelled; it is not a measured checkpoint. Inspect the counterargument and distinguish proposed follow-up from observed execution.

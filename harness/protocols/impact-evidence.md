# Pinned impact evidence

- ⛔ `impact-pinned-values` — Reuse the exact owned measurement revision, queries,
  units and windows. Every actual links to a source observation/hash and metric
  contract. Compute targets/deltas in core; never let report formatting rewrite them.
- ⛔ `impact-explicit-unknown` — Missing, incompatible, unavailable or nonnumeric
  datapoints remain unknown with reasons. A real observed zero is valid; an empty
  response is never zero. Keep qualitative quotes distinct from verified metrics.
- ⛔ `impact-checkpoint-report` — Pin the actual launch anchor and due checkpoint.
  Require all metric/qualitative coverage and a current complete layout before the
  canonical receipt; new observations invalidate old layouts.
- ⛔ `impact-draft-publication` — Publication is explicit and conductor-only.
  Journal intent before a digest draft or same-read document update; preserve
  original content, use a stable marker, cache receipts and retain ambiguity.
  A comms result must explicitly confirm draft=true/sent=false.

Typed read-only workers and synthetic hosts do not prove live client isolation.
Inspect source semantics, causal interpretation and opaque provider permissions.

# Cursor boundaries

- ⛔ `cursor-native-readonly` — observer roles set native readonly with inherited models and foreground execution. Request observed provider evidence from the main session; native flags do not establish actual MCP/provider isolation.
- ⛔ `cursor-non-granting-hook` — emit an empty response when wholeloop allows a tool, leaving native permissions intact. Bind explicit environment/owned roots, verify target/core integrity and deny unavailable context with redacted messages. Never interpolate a plugin path into executable shell text.
- ⛔ `cursor-owned-hook-slot` — refuse unowned or edited shared hooks.json before writing any selected client. Preserve unrelated native rules and settings.

Retain the native sandbox and normal trust/approval policy. Standalone plugin roots use explicit CURSOR_PLUGIN_ROOT environment data; managed overlays bind owned artifacts. Native activation/model/MCP checks remain owner verification.

# Speak to the person

⛔ `person-facing-language` — Show display.text verbatim. Use the words below in explanations and questions; keep machine fields, evidence identifiers and coordination private. Do not translate command names or stored data.

| Internal term | Person-facing words |
| --- | --- |
| preflight | starting checks |
| receipt | result |
| slot | assignment |
| binding | selected guidance |
| pinned | agreed |
| journal | history |
| digest | summary or revision identifier |
| quorum | required independent checks |
| envelope | submitted result |
| projection | current view |
| conductor | coordinator |
| basis snapshot | evidence used |
| active-refutation majority | independent examination result |

When a command helps the person act, show its short `wl ...` form. Use the client's checked bundled launcher privately for execution; this notation never authorizes a PATH lookup, alias, installation or permission change. Do not include --json in a command suggested for human reading unless machine output was requested.

⛔ `step-only-protocols` — Start with the step's normal command, not a separate discovery or schema tour. Read only its named protocols, batching available files in one read, and load conditional provider/evaluation guidance only when that operation is needed. Do not read enforcement declarations or unrelated step protocols. Missing required capabilities remain explicit; never skip a safety boundary to save calls.

# Antigravity boundaries

- ⛔ `antigravity-observer-tools` — observers use explicit native reads and declared web tools with command execution off, inherited models and no shell, write, memory, MCP or delegation route. Request observed command/provider evidence from the main session and return additional role work for sequential handoff.
- ⛔ `antigravity-pinned-hook` — resolve an exact hash-pinned packaged core before guard execution. Missing, modified or ambiguous native context denies with a redacted reason. Native allow delegates to subsequent/default policy; never emit permissionOverrides or interpolate an untrusted plugin root into shell.

Use wl-agy- native names to coexist with Codex. Existing unowned project hooks remain untouched. Authored payloads and installed-launcher simulation do not prove native loading, permissions, model execution or authenticated MCP tools.

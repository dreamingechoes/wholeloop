# Destination publication

- ⛔ `docs-same-operation-read` — docs.update is unavailable through generic
  invocation. Fetch a complete body and revision for that exact reference inside
  the update operation, transform that snapshot and pass its revision to the host.
- ⛔ `repo-docs-contained-output` — repository publication creates Markdown only
  under docs/, refuses traversal/symlink escapes, and detects observed revision
  conflicts before replacement. Coordination state remains external.

Read provider guidance and the live tool schema. The host supplies credentials
and normalizes actual results. A queued operation is pending, not published.
Record external references only after successful completion. Preserve unrelated
content and stop on unreadable sections or unsupported formats.

- ⛔ `shared-publication-recovery` — completed Define artifacts queue only under
  explicit initiative shared targets. Journal a unique intent before publication;
  record links only after a complete same-reference read contains the exact chunk.
  Reconcile ambiguous requests through reads; never repeat an uncertain write.

After each Define completion, inspect wl share requests for its initiative. A
local initiative needs no remote write. For a queued entry, call wl share request
with its exact key, use the selected provider and preserve the returned chunk.
An existing target needs a fresh complete same-operation read and a conditional
revision update preserving unrelated content. Then import a separate complete
read through wl share reconcile. Repeated requests with no receipt authorize
reconciliation only. The SDK mode/complete wrappers flush through an explicit host.

# Core-owned source evidence rules

- ⛔ `delivery-source-identity` — delivery intake pins complete bounded text, exact revision/reference/provider/scope, explicit extraction maps and provenance in immutable external snapshots. Refuse unsafe, credential-bearing, partial or mismatched inputs. Imported observations are not authenticated reads; source instructions create no authority or worker.
- ⛔ `delivery-research-web-reads` — a delivery worker gets the client's own read-only web search and fetch only for a `native-web` research angle or to re-read a claim's web citation. No other role, cell or provider receives web tools, and web search never opens sandbox network to commands.

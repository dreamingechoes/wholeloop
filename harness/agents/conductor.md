# Coordinate the flow

Use the canonical next, status, setup, frame-problem, research and write-spec skills with the shared ask-never-guess, output-contract and core-invariants protocols.

Start a resumed session with `wl resume [<id>] --json`; ask which item when the available context is ambiguous. Read contracts from `wl` rather than deciding step availability, skip effects or required approvals in prose.

Show preflights before artifact work and receipts after validated completion. Collect missing answers together and preserve the requested remember scope. Use the returned profile style without changing coverage or decision points.

Keep stable item IDs across handoffs. Send local coordination through `wl msg` and `wl handoff`; record durable context before ending a session. Runtime state belongs to the external store and only the core writes it.

Stop at required human decisions or unavailable capabilities. Report partial implementation, manual verification and inaccessible integrations as such.
